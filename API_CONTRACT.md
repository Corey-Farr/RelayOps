# RelayOps API contract
Base `/api`. JSON; collection responses are arrays, timestamps ISO UTC, identifiers UUID strings. Errors `{detail: string}`. Cookie `relayops_session` HttpOnly; login response `{user:{id,email,role},csrf_token:string}`. GET `/auth/me` same shape. All cookie-authenticated mutations require `X-CSRF-Token`. Roles admin/operator/viewer; viewer read-only, admin manages keys/users/projects.

- POST `/auth/login` `{email,password}`; POST `/auth/logout`; GET `/auth/me`.
- GET `/projects` -> `[{id,name,created_at}]`; POST `/projects` `{name}`.
- GET `/projects/{id}/keys` -> `[{id,name,prefix,created_at,revoked_at}]`; POST same `{name}` -> `{id,key}` (only reveal); DELETE `/keys/{id}`.
- GET `/destinations?project_id=` -> `[{id,project_id,name,url,event_types,enabled,created_at}]`; POST `/destinations` `{project_id,name,url,event_types:["*"],signing_secret?:string}` -> destination plus `signing_secret` once; PATCH `/destinations/{id}` `{enabled?:bool,name?:string,event_types?:string[]}`.
- POST `/events` API key `Authorization: Bearer ...` OR operator session; `{project_id,type,payload}`; `Idempotency-Key` required -> `{id,project_id,type,payload,created_at,status,deliveries:[]}` (201 new/200 duplicate). GET `/events?project_id=&status=&search=&limit=100` -> array of `{id,project_id,type,created_at,status,delivery_count}`. GET `/events/{id}` -> event and deliveries `[{id,destination_id,destination_name,status,attempt_count,region,policy_id,created_at,delivered_at,next_attempt_at,attempts:[{id,number,worker_id,region,started_at,ended_at,duration_ms,http_status,failure_category,error,trace_id}]}]`.
- GET `/deliveries?status=dead_letter` -> array deliveries with `event_id,type,destination_name`; POST `/deliveries/{id}/redrive` -> delivery.
- GET `/overview` -> `{events_total,deliveries_total,queue_depth,in_flight,delivered,dead_letter,success_rate,p95_latency_ms,throughput_per_minute,estimated_drain_seconds,slo:{target,window_hours,deadline_seconds,eligible,good,compliance,error_budget_remaining,burn_rate,short_burn_rate,sufficient_data},series:[{timestamp,accepted,delivered,failed}]}`. Rates are 0..1, null when unavailable; latency milliseconds. Series real hourly aggregates last 24h.
- GET `/workers` -> `{pools:[{region,paused,healthy,workers:[{id,region,last_heartbeat,version,capacity,state}]}]}`; POST `/workers/{region}/pause`, `/resume`.
- GET `/incidents` -> `[{id,title,description,severity,source,status,component,created_at,updated_at,evidence,timeline:[{at,action,actor}]}]`; GET `/incidents/{id}`; POST `/incidents/{id}/acknowledge` and `/resolve`.
- GET `/lab` -> `{enabled,mode,history:[{id,mode,created_at,actor,event_count}]}`; POST `/lab/scenario` `{mode:"normal"|"intermittent"|"rate_limit"|"latency"|"timeout"|"unavailable"}`; POST `/lab/generate` `{project_id,count:1..100,seed:42}` -> `{accepted,event_ids}`.
- GET `/policies` -> `{stable:policy,candidate:policy|null,canary_percent,history:[],comparison:[{policy_id,total,delivered,dead_letter,success_rate,p95_latency_ms}]}`; policy `{id,version,timeout_seconds,max_attempts,backoff_base,backoff_cap,created_at}`. POST `/policies/candidate` `{timeout_seconds,max_attempts,backoff_base,backoff_cap,canary_percent}`; POST `/policies/promote`, `/rollback`.
- GET `/audit?limit=100` -> `[{id,actor,action,resource,created_at,details}]`.
- `/health`, `/ready`, `/metrics` root endpoints unauthenticated.

Backend commands: `alembic upgrade head`; `python -m relayops.bootstrap`; `uvicorn relayops.main:app --host 0.0.0.0 --port 8000`; `python -m relayops.workers.runner`. env names forthcoming in backend config.
Demo signature: headers `X-RelayOps-Event-ID`, `X-RelayOps-Delivery-ID`, `X-RelayOps-Timestamp`, `X-RelayOps-Signature` (`sha256=` hex). Canonical bytes ASCII timestamp + `.` + raw request body; HMAC SHA256 using DEMO_SIGNING_SECRET. Sink `/webhook`; authenticated mode control POST `/control` `{mode,seed:42}` header `X-Control-Token: DEMO_CONTROL_TOKEN`; GET `/control` same auth.
